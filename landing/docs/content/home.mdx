## Overview

Welcome to the Leaflyte documentation. Leaflyte is a **local-first notes app** where every note is a real file on disk — markdown, code, SQL, HTML, and more — edited with Monaco and connected with wikilinks.

Use these docs to install the desktop app, run a self-hosted instance, and learn core features like search, AI, and VS Code capture.

## Popular topics

### Desktop app

Download from [leaflyte.app](https://leaflyte.app) for macOS, Windows, or Linux. Your vault lives in a folder you choose — no account required.

### Self-hosting

Run Leaflyte as a web service on your homelab or NAS. Start with [Self-Hosting Requirements](/getting-started/self-hosting-requirements/), then [Docker](/deployment/docker/) and [Reverse Proxy / SSL](/deployment/reverse-proxy-ssl/).

<Callout variant="note">
The desktop app is the primary experience today. Official Docker images and sync are on the [roadmap](/changelog/).
</Callout>
